### **Publish and Consume Public Content via the Web Gateway**

Diode hosts an Internet gateway at diode.link. Public content published via the Diode Network is accessible via this gateway at &lt;client-address&gt;.diode.link.

See <a href=" https://cli.docs.diode.io/docs/using/publish-static-content/" target="_blank" rel="noopener">this CLI doc for a quick start guide on how to publish content via the Web2 Gateway.</a>

If you want to access Private or Protected content, or just want to access the Diode Network without using the public gateway, install the Diode Client and see the article about [accessing Web 3.0 content](https://cli.docs.diode.io/docs/using/access-web3-0-content-run-a-local-gateway/).
