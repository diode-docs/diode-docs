&nbsp;

The Diode ZTNA console is a static web application and API server that uses your self-custody credentials to manage the control plane for the Diode Network.

Prior to 2026, users of the Diode Network had to configure the network through the CLI or through their own web applications.  The ZTNA console provides nearly full control of network definitions, access control lists, fleet contracts, etc... through a web UI and hosted API.
