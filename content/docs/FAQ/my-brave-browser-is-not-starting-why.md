Some Windows users report that tunneled Bookmarks attempt to launch the Brave browser, but fail and ask them to install.<br><br>On Windows, Brave MUST be installed to the canonical installation path at "C:\\\\Program Files\\\\BraveSoftware\\\\Brave-Browser\\\\Application\\\\brave.exe"n (64 bit) or "C:\\\\Program Files (x86)\\\\BraveSoftware\\\\Brave-Browser\\\\Application\\\\brave.exe" (32 bit).

If the Brave is not installed at that location with "brave.exe" as the launcher, it will not be able to be loaded.
