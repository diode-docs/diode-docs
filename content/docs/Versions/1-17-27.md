Diode Collab v1.17.27 was released on October 24, 2025.

*Note: v1.17.26 was an internal-only release and was not published*

* Bug Fixes
  * Remove Oasis Network dependency for signing up and device linking

## Fix: Remove Oasis Network dependency for linking devices and signing up

Due to updates the Oasis Network has been making to Oasis nodes, during Oasis maintenance periods, the signup / login / linked device process in Diode Collab was intermittently broken.  Diode has now disabled the dependency on the Oasis Network for signing up and device linking.
