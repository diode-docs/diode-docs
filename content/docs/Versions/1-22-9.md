Diode Collab v1.22.9 was released on September 2nd, 2026.

* Features
  * Migrate all Moonbeam zones to Base
* Bug fixes:
  * File listing stall that blocked file sync in some cases
  * MacOS tray icon

## Migrate all Moonbeam Zones to Base

As part of the unplanned Moonbeam end of life mitigations, all Moonbeam Zones have now been migrated to Base.  Free plans will show the "Base" icon in the quick access bar, and all Zones show their chain anchor in the Zone settings for Admins and Owners.

## Fix: File listing stall that blocked file sync in some cases

A major fix was deployed that addressed a number of file sync problem reports - full sync functionality has been restored.  The root cause was a power-efficiency release that was made in late June that truncated large file listings, causing some peers to be unable to get the full list of updated files from other peers.  This could result in some devices never syncing some files.  This has been fixed.

## Fix: MaxOS tray icon

The MacOS tray icon has been updated to work with the most recent MacOS version updates.  The app must be re-installed from the website to get this update -&gt; https://collab.diode.io/download .
