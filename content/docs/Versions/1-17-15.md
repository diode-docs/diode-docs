Diode Collab v1.17.15 was released on August 8, 2025

* Bug Fixes
  * File downloads broken on some machines if base installation earlier than v1.16.0
  * Improve device linking

## Fix: File downloads broken on some machines if base installation earlier than v1.16.0

A new database library released in v.1.17.13 introduced an incompatibility with older binary builds (any “Installation” version earlier than 1.16.0) which ultimately broke file downloads on some machines.  v.1.17.15 will arrive via auto-update and will fix the backwards incompatibility.

To avoid this type of issue in the future, QA will add tests with older binary base builds.  In any case, we do suggest users install the latest [version from the website](https://diode.io/download/#app) from time to time.

## Fix: Improve device linking

Depending on network state of a new device being added as a linked device, the initial linking request could fail.  In this case, the linking retry logic was not robust and would result in failed link attempts from time to time.  This has been fixed so that the system will successfully retry initially failed link attempts.
