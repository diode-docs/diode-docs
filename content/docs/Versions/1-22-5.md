Diode Collab v1.22.5 was released on August 13th, 2026.

* Features
  * Moonbeam -&gt; Base Zone remapping
* Bug fixes:
  * Remote API startup
  * File sync starvation on profiles with many Zones
  * Dismiss sync banner when sync complete

## Moonbeam -&gt; Base Zone remapping

This release adds an in-app map for Moonbeam Zones so that they are assigned their new Base addresses.  Although Zones now have a Base address, a subsequent release will still berequired for the full Base migration.

## Fix: Remove API Startup

The remote API would not startup on some systems - this has been fixed.

## Fix: File sync starvation on profiles with many Zones

Competing file syncs across multiple Zones could result in the entire sync system being stalled.  This has been fixed.

## Fix: Dismiss chat sync banner when sync is complete

The Peer and Canister sync status banner is now auto-dismissed when the sync has completed.
