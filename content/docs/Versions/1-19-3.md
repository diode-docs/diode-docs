Diode Collab v1.19.3 was released on March 24, 2026.

* Bug fixes
  * Oasis older linked devices not working

## Fix: Oasis older linked devices not working

This version was released to ensure that older linked devices would work on Oasis Zones.  There was a bug where an identity's older linked devices were not able to join into their main account on Oasis.  This has been fixed.
