Diode Collab v1.20.6 was released on June 4, 2026.

* Features:
  * Search in files and file listing
* Bug fixes:
  * Don't hide + Zone button behind bottom banner
  * Restore chat sent/read status to same line as message

## Search in files and file listing

A new search bar shows up above file/folder listings allowing you to search in the folder for filenames.

## Don't hide + Zone button behind bottom banner

When the bottom banner appears for call or update status, the "+" button was hidden behind it - this has been fixed.

## Restore chat sent/read status to same line as message

Chat sent/read status indicators were showing always on the next line after the message, which was wasting screen space.  These have been moved back to the end of the relevant line.
