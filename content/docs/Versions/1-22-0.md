Diode Collab v1.22.0 was released on July 16, 2026.

* Features
  * Add Base as beta chain layer
  * Show zone warning when all backup bots are offline
  * Performance improvements
* Bug fixes:
  * Duplicate emoji reactions when toggling across linked devices
  * Linked-device chat delivery check marks
  * Stuck transactions when reconciling BNS
  * Waiting-for-sources transfers showing "From Nobody"

## Add Base as beta chain layer

Base has been added as a beta chain layer.  Although there are no selectable controls, this release is a preparatory release for a subsequent generally available Base option for anchoring Zones.

## Show Zone warning when backup bots are offline

If a Zone has a backup bot, but it is offline, a banner is now shown to warn Admins and Owners about potential Zone availability degradation.

## Performance improvements

File caching, file indexing, and zone mount-time have been improved.

## Fix: Duplicate emoji reactions when toggling across linked devices

Reacting to a message from a linked device no longer duplicates a reaction made from another linked device.

## Fix: Linked-device chat delivery check marks

If a linked device views a chat message from another linked device, the state was sometimes showing as a grey check although that would have been impossible since the linked device successfully received the message.  The logic has been fixed for this situation.

## Fix: Stuck transactions when reconciling BNS

When reconciling account names across linked devices transactions (e.g. Oasis) were getting stuck - this has been fixed.

## Fix: Waiting-for-sources transfers showing "From Nobody"

File transfer history no longer shows "from nobody" - if there are no sources, the transfer isn't shown since there is actually not a file transfer happening or possible.
