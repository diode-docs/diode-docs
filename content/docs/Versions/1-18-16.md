Diode Collab v1.18.16 was released on January 16, 2025.

* Features
  * Show advanced chat features even when disabled
  * Improved Discover card publishing
* Bug Fixes
  * Mobile Zone and Profile image setting

## Show advanced chat features even when disabled

Advanced chat features (Pin message, emoji reactions) are now shown even when disabled due to the Zone's plan.

## Improve Discover card publishing

Discover card publishing has been improved - edits to cards are now reflected immediately, and better user feedback is provided about the card's publication state.

## Fix: Mobile Zone and Profile image setting

Mobile can now be used to set the image for a Zone icon or a Profile picture/icon.
