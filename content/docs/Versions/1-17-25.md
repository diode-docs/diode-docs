Diode Collab v1.17.25 was released on October 01, 2025.

This release includes significant updates to the file and sync handling subsystem.

*Note: v1.17.24 was an internal-only release and was not published*

* Features
  * Improved download queue priority
* Bug Fixes
  * App freeze on MacOS after waking from sleep

## Improve download queue priority

The file download queue algorithm has been improved to help Zones complete sync, especially on resource constrained devices.

## Fix: App freeze on MacOS after waking from sleep

The app would sometimes be frozen for up to 10 seconds on MacOS after waking from sleep.  This is now fixed.
