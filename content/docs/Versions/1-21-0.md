Diode Collab v1.20.9 was released on July 7, 2026.

* Bug fixes:
  * Application crash on 32-bit systems
  * Various performance improvements

## Fix: Application crash on 32-bit systems

32 bit systems would crash upon running a new function introduced in 1.20.8 that calculates bandwidth usage.  This would present an "Oops you found a bug" and is primarily seen on 32 bit Raspberry Pi systems.  These systems will receive an auto-update to this version (1.20.9), but must be manually restarted in order to apply the update.

## Fix: Various performance improvements

A number of updates have been made with respect to CPU, power, and page load time.
