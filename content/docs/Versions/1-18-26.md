Diode Collab v1.18.26 was released on March 2, 2026.

* Bug Fixes
  * Navigation history

## Fix: Navigation history

A bug was introduced to a Zone's navigation history where, on certain Zones, a viewing history lookup would fail resulting in the Zone directing the user to the All Drives page (or file root page) when they navigated to the Zone.  This has been fixed.
