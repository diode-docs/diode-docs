Diode Collab v1.17.28 was released on October 31, 2025.

* Features / Improvements
  * Increase Zone setting updates and file sync speed on Mobile
  * Unify search bar styles across the app
* Bug Fixes
  * Add file from device
  * Don't downgrade to Nomad when changing plans

## Improve Zone setting updates and file sync speed on mobile

Mobile devices, particularly Android based systems, have slower disk performance.  This was resulting in a newly configured device taking a long time to fully join a Zone - particularly if it was joining many Zones (as in the case of a Linked Device) or if the Zone it was joining had many files.  The database performance underpinning the file capabilities was grammatically improved, allowing Zones to complete syncing even in the case of thousands of pending files.

## Unify search bar styles across the app

The various "search bar" controls in the app were using different visual styles - these are all now aligned and some incorrect visual button offsets are now fixed.

## Fix: Add file from device

Version 1.17.27 briefly broke the ability to add a file from the local device via the "+" file table control.  This has been fixed.  Despite the "From Device" option being broken, dragging/dropping and file system additions were still working fine.

## Fix: Don't downgrade to Nomad when changing plans

The Zone plan upgrade system was first downgrading the plan to Nomad before applying the new plan upgrade.  This could result in paid plans that are upgrading to a higher plan inadvertently briefly resetting certain Zone settings to the Nomad default settings.  This was particularly disruptive to the file sync policy because Nomad has a default "Off" policy - this could force all Zone members into a file-sync "Off" state, requiring each member then to manually  re-set their device's file sync state to the previous / desired state.
