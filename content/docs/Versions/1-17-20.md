Diode Collab v1.17.20 was released on September 3, 2025.

* Features
  * Show chat sync progress
* Bug Fixes
  * Set profile image
  * Repeated share re-writes

## Show chat sync progress

We've added some banner information at the top of chats if a chat is in the process of getting updates from other Team Members.

When Diode Collab loads, one of the first things it does is to establish connections with other peers in your Zone and then sync the most recent chat state from them.  This process can sometimes take some time (1-5 seconds if you run Diode Collab as a daily driver, sometimes up to a minute if you run Diode Collab infrequently but are part of many Zones).   These new banners will help users identify the status of the chat and their app's loading state.

## Fix:  Set profile image

Profile image setting was broken on some platforms - this has now been fixed.

## Fix: Repeated share (web link) re-writes

Web links were being re-written to the Zone every so often even if there was no substantive change.  This bug was due to incorporating ordering information in the web link meta information - when the ordering was changed, the system would iterate the web link version.  Now, non-functional local changes are not reflected as changes to the underlying web link / share.
