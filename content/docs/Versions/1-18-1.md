Diode Collab v1.18.1 was released on November 14, 2025.

* Features
  * Enable Private Drives on legacy Enterprise plans
* Bug Fixes
  * Improve performance for Private Drives

## Enable Private Drives on legacy Enterprise plans

Customers using Zones with the "Enterprise" plan are now enabled with the Private Drives feature.

## Fix: Improve performance for Private Drives

v.1.18.1 was a performance release to address specific slowdowns experienced by some users due to the Private Drives release.  Specifically, application slowness could be experienced when the local device created new blockchain transactions, if the device had multiply-profiles installed, or if it was actively running file backup.  These performance impacts have been improved.
