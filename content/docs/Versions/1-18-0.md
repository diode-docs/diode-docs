Diode Collab v1.18.0 was released on November 14, 2025.

* Features
  * Private Drives
* Bug Fixes
  * Add file existence check before renaming
  * Add name conflict checks when renaming drives and zones
  * Clean up mechanisms to leave zone
  * Fix zone location on disk setting
  * Fix redirect upon Zone load
  * Fix cannot change plan issue
  * Update file sync check for edit button state
  * Disable edit actions when file sync is off
  * Fix macos icon (needs new app download)

## Private Drives

The “Private Drives” feature allows organizations to control access to information so that specific members can get private access to specific Drives within the Zone.

Private Drives allows a single Zone to deploy multiple “drives”, each with different team member permissions. Each drive has unlimited storage, unique permissions, and independent settings.

This changes the game for how teams are using Diode to collaborate - before many teams were using multiple Zones to collaborate due to file permission limitations. Private Drives allows these teams to consolidate into a single Zone.

## Fix: Add file existence check before renaming

The "Rename" option in the context menu in the file/folder view now checks to ensure the new name being set is unique.

## Fix: Add name conflict checks when renaming drives and zones

When renaming a Zone or Drive, the system now checks to ensure the new name being set is unique.

## Fix: Clean up mechanisms to leave zone

You can now leave a Zone as an owner, and file cleanup is now also done on Windows devices.

## Fix: redirect upon Zone load

The app would sometimes redirect to the file/folder page when the Zone completed loading.  This was undesired behavior, and has been fixed.

## Fix: cannot change plan issue

It was not possible to upgrade a Zone's plan from the Nomad plan - this has been fixed.

## Fix: disable edit actions when file sync is off

The MD Editor no longer allows editing if file sync is turned off.  In the past, it was possible to edit a file with file sync off, leading the user to believe they were making modifications that would be shared with everyone.  These modification could be later overwritten accidentally if they changed their file sync state.  Note: the old version was backed up, but it was disconcerting nonetheless.

## Fix: MacOS icon

The MacOS icon will load again on the latest version of MacOS if you install v1.18.0 <a href="https://diode.io/download#app" target="_blank" rel="noopener">from the website</a>.  The icon will not be fixed via auto-update.
