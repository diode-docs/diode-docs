Diode Collab v1.18.20 was released on February 4, 2026.

* Bug Fixes
  * Immediate chat relaying
  * Join codes sometimes show “invalid”
  * Device linking
  * Improve blockchain efficiency
  * Profile data intermittent load
  * Reduce CPU usage

## Fix: Immediate chat relaying

Private chats were not being relayed by bots. If you didn't have a direct connection to the other person, chat delivery could take up to one minute.

## Fix: Join codes sometimes show “invalid”

Join codes could sometimes show “Invalid” when attempting to join a zone. This was due to a race condition in blockchain responses. Eg. If the Zone was anchored on Moonbeam, a race in which Moonbeam lookup took a long time but the Diode L1 immediately responded could produce the “Invalid” response.

## Fix: Device linking

Device linking had a regression since 1.18.17. This has been fixed.

## Fix: Improve blockchain efficiency

Blockchain state change is now event driven. The Diode Network has been upgraded to provide change events.

## Fix: Profile data intermittent load

Some profiles could not be loaded immediately. This has been fixed.

## Fix: Reduce CPU usage

CPU usage has been improved significantly by moving certain highly queries data structures to memory vs disk.
