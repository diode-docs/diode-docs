Diode Collab v1.18.15 was released on January 13, 2025.

* Features
  * Chat attachment preview
  * Open with / share / download actions for mobile
* Bug Fixes
  * Reference a folder in chat
  * Correct path when importing file from OS share action
  * Zone load dependency error

## Chat attachment preview

When clicking a file in chat, the file preview is popped open inline with the chat view - you are no longer navigated to a sub-view.  The pop-up then provides options for what you'd like to do next.

## Open with / share / download actions for mobile

Chat attachment pop-up and file actions now support mobile "open with", "share", and "download" for the file.  This should increase usability significantly for mobile users wanting to view the file in their app of choice.

## Fix: Reference folder in chat

Certain folder paths could not be referenced in a chat.  This has been fixed.

## Fix: Correct path when importing file from OS share action

The file path was incorrect when importing a file from your system via the OS's "share" action.  The file would be correctly added to the Zone, but the view would be redirected to a non-existent page due to the incorrect path.  This has been fixed.

## Fix: Zone load dependency error

The "Allow channels to send push notifications on all messages" feature in the previous release introduced a new library dependency that was not always available upon system load for newly added Zones.  This was observed on an Android device.  This has been fixed.
