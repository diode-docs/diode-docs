Diode Collab v1.18.9 was released on December 11, 2025.

* Features
  * Redesigned community "Discover" cards

  Bug Fixes
  * Remote file listing performance
  * Join progress stalled
  * Ensure plan is refreshed when Zone is loaded

## Redesigned community cards

The community "Discover" Zone cards are redesigned to be smaller so that they are easier to browse.

![](/uploads/image-208.png)

## Fix: Remote file listing performance

For Zones that had many files (&gt; 1k), member operating in file sync: upload only mode could experience very slow Zone performance, especially when there was only one other member that operated as a source of the files (like a Bot).  This release dramatically improves the performance of Zones in this configuration.

## Fix: Join progress stalled

Sometimes the "Initializing Zone" progress page could stall even though the Zone completed initializing.  This has been fixed.

## Fix: Unknown error on certain iOS Zones

Reinstalling a new iOS release from the app store changes the storage path on the device.  This could create an "Unknown error" message on Zones that were in the initialization state on the previous storage path, and the Zone could never be fully joined.  This has been fixed.

## Fix: Ensure plan is refreshed when Zone is loaded

The Zone's billing plan is now refreshed when the Zone is loaded.  This fixes a race condition in Zone startup for new Zones that were created by a new user whose identity was not yet fully settled on-chain.
