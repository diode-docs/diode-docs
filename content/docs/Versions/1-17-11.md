Diode Collab v1.17.11 was released on July 16, 2025

* Bug Fixes
  * PIN challenge repeats

## PIN challenge repeats

Version 1.17.10 introduced a bug where the PIN challenge would show up repeatedly if the system had multiple accounts that had previously had a PIN enabled but that was subsequently disabled.  This has been fixed.  <br>If your system is in this state and is not able to get the 1.17.11 update, you should install an update for the app from https://diode.io/download.
