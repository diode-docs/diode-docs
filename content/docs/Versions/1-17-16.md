Diode Collab v1.17.16 was released on August 19, 2025

* Features
  * Discover page search and listing improvements
  * More verbose connection problem warnings
* Bug Fixes
  * Channel mentions create push notifications
  * Discover page image and blurb updates
  * Accepting an invitation on a duplicate Zone name

## Discover page search and listing improvements

The Discover page now loads card listings faster (search is more immediately pertinent), and also paginates the listings (first page rendering is faster).

## More verbose connection problem warnings

More verbose connection problem warnings have been added to the sign up and log in process.  In the past, the app would sometimes not progress (silently fail) through sign up and log in if the system (usually a phone) were not connected to the Internet.

## Fix: Channel mentions create push notifications

Channel mentions now create push notifications!  This significantly improves the ability to react to group conversations on mobile devices.

## Fix: Discover page image and blurb updates

Updates to a Zone's icon, card image, blurb, and About page were sometimes not being shown on the Discover page.  This has been fixed and the speed of updates has also been improved - most updates will be visible within one minute.

## Fix: Accepting an invitation on a duplicate Zone name

It was not possible to accept an invitation to a Zone if it had the same name as an existing Zone.  This has been fixed.
