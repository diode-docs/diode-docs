Diode Collab v1.19.2 was released on March 19, 2026.

* Features
  * Oasis Zones
  * Internet Computer canister support for Oasis
* Bug fixes
  * Canister file download
  * Invite code sync can overwrite code visibility for owner
  * Recheck tracking for Drives

## Oasis Zones

We are excited to officially release support for Oasis anchored Zones!

Diode Collab has long secured the data plane and routing authenticity with blockchain anchored identities and end to end encryption. The routing authenticity is a step above security conscious apps like Signal, that rely on vendor (Signal) modifiable servers and the telco networks for elements of routing and identity. With Oasis, Diode takes our commitment to privacy and security even a step further and introduces the full protection of control plane meta information.  This represents full spectrum security for communication systems - a first for team based collaboration apps!

## Internet Computer canister support for Oasis

Along with the Oasis Zones, we have integrated Internet Computer canisters with Oasis functionality so that a Canister's encrypted storage can be used to propagate presence, meta, and files for Oasis anchored Zones.

## Fix: Canister file download

Certain files could get corrupted and were not downloadable from ICP canisters, this is fixed.

## Fix: Invite code sync can overwrite code visibility for the Owner

When a Zone Owner created an invitation code, it could disappear in the user interface and just say "Unknown" after a little while (sometimes quickly).  While the code was still valid and usable by the system, the Owner wasn't able to see it or copy it in these situations.  This has been fixed.

## Fix: Recheck tracking for Drives

Private Drives now have a better tracking mechanism for file status.
