Diode Collab v1.18.25 was released on February 28, 2026.

* Features
  * Dioder profile boost
  * Oasis profiles
  * Table action tool tips
  * New "Ignore All" button when many Zone invitations arrive
* Bug Fixes
  * Canister upload/download fallback

## Oasis profiles

Diode has been collaborating with the Oasis Network to enable Oasis-anchored profiles and usernames on their Sapphire Privacy Network.  This integration builds on Diode's blockchain partnerships with <a href="https://internetcomputer.org/" target="_blank" rel="noopener">The Internet Computer </a>and <a href="https://moonbeam.network/" target="_blank" rel="noopener">Moonbeam Network</a> to add important privacy to the contract layer.

When you run Diode Collab v.1.18.25 and later, your account will be automatically enabled on Oasis Sapphire.

Full Diode Collab Zone anchoring is in testing and will be made available in an upcoming release.

In addition to Diode Collab, Diode has been using Oasis Sapphire for anchoring zero trust access control lists in our [ZTNA Console](https://ztna.diode.io) since 2025.  The privacy at the contract-contents layer is important for unlocking blockchain-anchored capabilities that may include unstructured data that is otherwise difficult to secure (e.g. Real World Asset contracts, Access Control List meta, etc.)

## Dioder profile boost

If a given Zone doesn't support chat reactions, chat pinning, and other upcoming advanced features, you are able to still use the features for just your account by getting the "Dioder" profile boost.

The Profile area has a new settings item to manage your DIoder profile boost status.  It will show "Active" if you have the Dioder boost, and "Inactive" if you don't :<br>![](/uploads/image-210.png)

You can learn more about the boost, and how to get it, <a href="https://app.docs.diode.io/docs/faq/what-is-the-dioder-profile-boost/" target="_blank" rel="noopener">here</a>.

## Table action tool tips

Tool tips are now shown on folder area action buttons when hovering (desktop) or long-clicking (mobile).

## New "Ignore All" button when many Zone invitations arrive

If you have more than one un-resolved Zone invitation, you now have the option to "Ignore All" to clear them all.
