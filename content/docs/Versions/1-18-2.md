Diode Collab v1.18.2 and v1.18.3 (fast follow) were released on November 14, 2025.

* Features
  * Add backup summary to Zone header

  Bug Fixes
  * Disable edit button for out of date files
  * Move for renamed Drives
  * Improve performance for Discover page and Zone checks

## Add backup summary to Zone header

Devices that have the "File Backup" feature enabled will now see the backup icon in the Zone header instead of only in the Drive settings.  The Zone header's backup icon provides an overview of the backup status for all Drives in the Zone.

![](/uploads/image-203.png)

## Fix: Disable edit button for out of date files

Upload only peers were able to edit files that were out of date.  The edit action would create a new file, which would overwrite any other more recent versions out there.  This has been fixed - edit is now disabled until the file on the local device is the most recent one.

## Fix: Move for renamed Drives

The Drive move process now works for Drives and Zones that have been renamed.  Previously, the new desired path would become malformed.

## Fix: Improve performance for Discover page and Zone checks

The app's Discover page performance has been improved, as have other Zone plan related checks.
