Diode Collab v1.20.8 was released on July 1, 2026.

* Bug fixes:
  * Oasis identity address divergence across Linked Devices
  * Various performance improvements

## Fix: Oasis identity address divergence across Linked Devices

Certain accounts that began using Oasis identities in late 2025 could have divergent Oasis identity addresses across Linked Devices.  This has been fixed.

## Fix: Various performance improvements

A number of database and connection related performance improvements have been made.
