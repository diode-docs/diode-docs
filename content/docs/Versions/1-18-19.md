Diode Collab v1.18.19 was released on February 2, 2026.

* Features
  * Add gear icon to channel header
  * Multi-user invites
* Bug Fixes
  * Share file listing
  * Canister update
  * Clear tray icon when messages read
  * PIN-protected access to backup codes
  * Adjust size of in-line chat images
  * Better error handling during signup during poor Internet connectivity

## Add gear icon to channel header

Chat channels now have a gear icon in the header to make it easier to view and configure settings (e.g. turn notifications on/off).  Before, the user had to click the "Channels" title in the Quick Access bar, then select a channel, and then go to settings.

## Multi-user invites

You can now invite many people at one time from the Invite Team modal.  The app will auto-provision an invite code if you opt to send the invite via Email, and also has options to copy an existing invitation code to send out yourself.

## Fix: Share file listing

The web link shares API had a regression that resulted in many web links being inaccessible.  It is now fixed.

## Fix: Canister update

Some peers were not interacting with the Zone's canister.  This has been fixed.

## Fix: Clear tray icon when messages read

The tray icon wouldn't clear the red dot until the app was restarted.  This has been fixed - it now clears when the last unread message is read.

## Fix: PIN protected access to backup codes

If a PIN was enabled on the device, it was not possible to access the backup code page.  The app would challenge for PIN in order to access the backup code, but a successful entry would navigate to the PIN area.  This has been fixed.

## Fix: Adjust size of inline chat images

If a chat image is too big to fit into the history pane, it is automatically resized now.  In the past, some sizes of large images would be rendered full size in the history pane, making them hard to see.

## Fix: Better error handling during signup when Internet connectivity is poor

If Internet connectivity is poor during signup, the app detects communication failures on a more granular basis so that the user can be given informative feedback instead of just "failed".
