Diode Collab v1.18.11 and v1.18.12 was released on December 18, 2025.

* Features
  * Embellish team stats with startup time, sub-drives, binary version, and db size
  * Show tip if "+" reclicked on Discover page
  * Add chat icon to All Members for members with unread messages
  * Add Clear Notifications to Zone settings
  * Clarify Leave and Unlink Zone actions
* Bug Fixes
  * File creation failure
  * False-positive "Pending"
  * Prevent showing breadcrumbs in About page
  * Fix high CPU usage from online status updates

## Embellish team stats

In order to help our Zone Admins help their Members, we've added additional information to the Admin/Owner stats screen for each member - they can now see their Member's start time, sub-drive count, binary application installation version, and size of their profile databse.

## Show tip if "+" reclicked on Discover page

A flash message tip is shown if the Zone Selector "+" is clicked when the user is already on the Discover page to prompt them to select an option on the page.

## Add chat icon to All Members for members with unread messages

The All Members team listing now shows a little chat icon beside any member that may have unread messages.  The view also shows which members are "Pending" and also allows you to sort by Name or Role.

## Add "Clear Notifications" to Zone Settings

Some users have experienced a notification bubble on their Zone that is not being cleared when they have read all visible notifications/unread messages.  The cause of this was often an unread message in a previously archived channel, but could also come from a direct message by a Team Member who is no longer showing in the Quick Access bar because their message is so old.  For these edge cases, we've included a "Clear Notifications" button in the Zone Settings to allow you to clear all notifications in the Zone, regardless of source.

## Clarify Leave and Unlink Zone actions

We've added an "Unlink" button the the Zone settings for all roles, and have also clarified the warning pop ups that appear if you click Unlink or Leave Zone so it is more clear what those actions will result in.

Unlink Zone is just removing it from your current device - your account is still part of the Zone and you can still interact in the Zone from your other devices if desired.  You can re-join (Restore) an Unlinked zone at any time on your current device.

Leave Zone is removing your account from the Zone.  This will remove it for all of your devices, and it will delete the Zone folder/files from your system.  If you are the Zone owner, it will further destroy your contractual ownership of the Zone and make it forever inaccessible.

## Fix: File creation failure

Files could not be created if the directory didn't exist on disk - as is often the case in a system running a Zone in upload-only mode.  This has been fixed.

## Fix: False positive "Pending"

Some users who had actively joined the Zone were still be shown as "Pending" in the Quick Access bar and in the All Members list.  This has been fixed.

## Fix: Prevent breadcrumbs in the About page

The About page editor was showing breadcrumbs to the Zone settings details.  Breadcrumbs have now been disabled for About pages.

## Fix: Prevent high CPU usage from online status updates

We switched to a "token ring" presence notification system (aka "Gossip") in v.1.18.7.  However, there was a bug in which CPU usage could go &gt;100% (multi-core) if no members at all were online to relay presence.  This has been fixed.
