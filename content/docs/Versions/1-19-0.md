Diode Collab v1.19.0 was released on March 17, 2026.

* Features
  * Chat reply threads
* Bug fixes
  * Invites sometimes don't arrive on iOS
  * Don't allow creation of folders or files with empty names
  * Allow drive listing to scroll after adding a file or folder
  * Reduce CPU usage when app is in background

## Chat reply threads

Chat reply threads are a major new feature that allows replies to be made to a message in a "thread" so that they don't disrupt the main chat timeline.  This is a highly requested feature, and we are happy to release it to the wild!

## Fix: Invites sometimes don't arrive on iOS

iOS systems could sometimes miss an invite when the a new team member was invited by name.  This has been fixed.

## Fix: Don't allow creation of folders or files with empty names

Previous to this release, it was possible to create a folder or file with no name at all.  These files were usually accidentally created and were typically invisible on the host system.  We've blocked the creation of a file or folder now unless a name is provided.

## Fix: Allow drive listing to scroll after adding a file or folder

There was an edge case that would disable "infinite scroll" if a file or folder was added to a folder that contained many files.  This has been fixed.

## Fix: Reduce CPU usage when app is in the background

CPU usage is now tamped-down when the app has been in the background for some time
