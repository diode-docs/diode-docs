Diode Collab v1.17.14 was released on July 31, 2025

* Bug Fixes
  * Display file status correctly in non-sync and upload-only mode

## Fix: Display file status correctly in non-sync and upload-only mode

The file / folder pages were not showing file status correctly for devices in non-sync and upload-only mode since 1.17.13 release.  For example, if a file was deleted, the page would show the file with a "check" indicating the file was on-disk and up to date when in reality it was removed from disk.  This has been fixed.
