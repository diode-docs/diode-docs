Diode Collab v1.18.10 was released on December 15, 2025.

* Bug Fixes
  * File listings in sync:off mode

## Fix: File listing in sync:off mode

For some Zones with members operating in sync:off mode, the members could never get the full file listing because the list was too long and the system truncated the list for these members.  This has been fixed.
