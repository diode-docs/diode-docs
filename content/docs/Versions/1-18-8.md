Diode Collab v1.18.8 was released on December 08, 2025.

* Features
  * Reduce memory usage

  Bug Fixes
  * Zombie zone creation race condition
  * Unknown error on certain iOS Zones
  * Filter archived channels from list
  * Mobile can't find Zone from push notification

## Reduce memory usage

Memory usage in the app has been decreased by about 50%.  This should increase the performance of the app noticeably for most users.

## Fix: Zombie zone creation race condition

Some older versions had created "zombie" Zones that couldn't be used.  This release cleans those broken Zones up and also removes the race condition that created them.

## Fix: Unknown error on certain iOS Zones

Reinstalling a new iOS release from the app store changes the storage path on the device.  This could create an "Unknown error" message on Zones that were in the initialization state on the previous storage path, and the Zone could never be fully joined.  This has been fixed.

## Fix: Filter archived channels from list

When sharing a file or folder via chat, archived channels are no longer shown as options.

## Fix: Mobile can't find Zone from push notification

Push notifications would sometimes not take the user to the correct message, showing "Can't find Zone" when the app was opened by clicking on the push notification.  This has been fixed.
