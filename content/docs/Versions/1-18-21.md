Diode Collab v1.18.21 was released on February 10, 2026.

* Features
  * "Add Folder" button in file browser
* Bug Fixes
  * Various stability improvements
  * Show file syncing indicator when uploading files in upload-only mode
  * Weblink rapid creation in new Zones

## "Add Folder" button in file browser

An "Add Folder" button has been added when viewing the in-app file browser.  This allows the user to easily organize files being "shared" into the app, as is often the case on mobile when adding pictures to a Zone.

## Fix: Various stability improvements

A number of stability improvements were made that improve connection handling and message processing in the app.

## Fix: Show file syncing indicator when uploading files in upload-only mode

The file syncing icon now spins when uploading a file while in upload-only mode.  In the past, the icon wouldn't spin unless the Zone was in 2-way sync mode.

## Fix: Weblink rapid creation in new Zones

New Zones can now create Weblinks immediately.  In the past, the Zone's blockchain UUID had to have been fully registered on the blockchain before a weblink could be successfully created or used.
