Diode Collab v1.17.17 was released on August 20, 2025 to fix an app crash issue due to pausing the network

Diode Collab v1.17.18 was released on August 21, 2025 with minor administrative updates

* Bug Fixes
  * Pause network crashes the app

## Fix: Pause network crashes the app

The Pause Network icon menu option exposed a bug in the underlying network client that would hard crash the app when the network was paused.  This has been fixed.  If your app is in a crash loop due to pausing the network, you will need to <a href="https://diode.io/download/#app" target="_blank" rel="noopener">re-install from the website to install version 1.17.17</a> or later containing this fix.
