Diode Collab v1.22.6 was released on August 27th, 2026.

* Features
  * Move, rename, bulk-delete files when in upload-only mode
  * Sign in automatically if the profile exists on the device
* Bug fixes:
  * Improve device linking
  * Moonbeam-EOL related edge cases
  * External chat links open in system browser

## Move, rename, and bulk-delete files when in upload-only mode

Admin and Owner roles can now move, rename, and bulk-delete files when in upload-only mode even if they don't have the files on disk.

## Sign in automatically if the profile exists on the device

If the users types in a profile that is already on the device, the profile is opened rather than a "linked device" attempt launched.

## Fix: Improve device linking

Device linking has been made more stable

## Fix: Moonbeam-EOL related edge cases

There were multiple Moonbeam end of life related edge cases still in the app - the vast majority of these have been cauterized.

## Fix: External chat links open in system browser

Chat links were opening in the web kit browser (in-app) instead of system browser.  This has been fixed.
