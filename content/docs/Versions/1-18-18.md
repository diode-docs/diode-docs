Diode Collab v1.18.18 was released on January 27, 2025.

* Bug Fixes
  * Private chat fix for chats created before February 2024

## Fix: Private chat fix for chats created before February 2024

This fixes an issue where certain private chats could disappear for the users in certain Zones.

As part of the v.1.18.17 release, Zone contracts were upgraded to require explicit identification for chat participants (related to granular checks required by Oasis TEE blockchain integrations). This identification check would fail for private chats created on the Diode L1 Blockchain before February of 2024, resulting in the chats becoming invisible to users.  This was solely a permission scoping issue with older private chat channels - no data or settings were changed or lost.
